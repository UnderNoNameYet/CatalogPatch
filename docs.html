REFERENCE / ENGINE 0.1

Know exactly what
the converter touches.

CatalogPatch is a browser-side worksheet transformer. This reference describes supported source patterns, output fields, findings, and the checks that remain outside the product.

01 / SUPPORTED INPUT

Source profiles

ProfileRecognized patternsCurrent behavior
WooCommerceType, SKU, Name, Regular price, Images, Attribute columnsSkips variable parent rows, links variations through Parent, groups variants under the parent handle, converts kg/lb/oz when declared.
SquarespaceProduct Type, Product URL, Title, Option Name/Value, Hosted Image URLsMaps product URL to handle, options to variants, sale price to price plus compare-at price, and visibility to draft/active status.
SquareToken, Item Name, Variation Name, SKU, Category, PriceMaps item and variation identity, GTIN/barcode, prices, quantities, and archived state. Location-specific inventory still needs review.
ShopifyHandle, Title, Variant SKU, Variant Price, Image SrcCan preflight and normalize an existing classic product export. Store-specific fields not represented in the engine are left out.
Generic CSVCommon aliases for title, SKU, price, inventory, images, options, and metadataAuto-maps likely headers. The user must approve every mapping before conversion.

02 / FILE PARSING

Structure handling

  • Comma, semicolon, and tab delimiter detection.
  • Quoted commas, escaped quotes, CRLF/LF records, and quoted multiline descriptions.
  • UTF-8 decoding with a Windows-1252 fallback in the browser.
  • Duplicate and blank headers receive deterministic internal names.
  • Files larger than 30 MB are rejected in the current browser beta.
KEEP IDENTIFIERS AS TEXT

Spreadsheet software can silently change long SKUs and barcodes into scientific notation. CatalogPatch flags scientific-looking identifiers but cannot reconstruct digits already discarded by the spreadsheet.

The export uses a conservative classic product CSV schema. Shopify can change its accepted fields. Its current upload preview is the final authority.

04 / FINDINGS

What blocks a clear preflight

SeverityExamplesAction
CriticalMissing title, invalid price, duplicate SKU, scientific-notation SKU, duplicate option combination, more than 100 standard variantsUnderstand and correct before importing.
WarningMissing SKU, negative stock, non-HTTPS image URL, unnamed option, inconsistent CSV row widthVerify against the source and Shopify preview.
NormalizedCurrency symbols, comma decimals, known weight-unit conversions, generated handlesInspect representative rows before import.

05 / SAFE WORKFLOW

Recommended import sequence

  1. Export a fresh backup from the destination Shopify store.
  2. Work from a copy of the source catalog.
  3. Approve the field map and keep the default output status as Draft.
  4. Resolve or explain every critical finding.
  5. Download the worksheet, audit register, and recipe.
  6. Upload to Shopify and inspect product, variant, image, and price counts.
  7. Import a small representative batch before the complete catalog.
  8. Publish only after manual verification.

06 / OUTSIDE THE ENGINE

What CatalogPatch cannot verify

  • Whether a remote image URL will remain available to Shopify.
  • Store-specific taxonomy, markets, metafields, locations, or app-owned fields.
  • Third-party platform exports that changed after this release.
  • Whether an import will overwrite existing products in the intended way.
  • Current Shopify limits, policy, or import behavior.
  • The commercial, tax, or legal accuracy of catalog information.
