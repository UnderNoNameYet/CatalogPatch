Last updated: August 25, 2026. This notice describes the current static beta hosted on GitHub Pages.

Local file processing

When you choose a CSV, TSV, or text file, CatalogPatch reads and transforms it with browser JavaScript on your device. The application does not intentionally upload the file, its rows, or generated exports to a CatalogPatch server. No CatalogPatch case or catalog database exists.

Website hosting

The site is hosted through GitHub Pages. GitHub and network providers may process ordinary request information such as IP address, browser details, requested assets, timing, and security logs under their own policies. Do not treat static hosting as anonymous access.

Browser storage and offline cache

A service worker may cache application code, styles, documentation, and fictional test fixtures for faster or offline reuse. The current app does not deliberately place your uploaded product rows into Cache Storage, cookies, or an analytics service. Closing or reloading the tab removes the active in-memory conversion run.

Downloads

Shopify worksheets, audit registers, and mapping recipes are generated as local browser downloads. You control where those files are stored and who receives them. Review them before sharing because they can contain commercial catalog data.

Analytics, accounts, and payments

The current beta has no CatalogPatch account system, advertising tracker, analytics SDK, payment form, or enabled checkout. If those facts change, this notice must be updated before collection begins.

Safer use

Use a trusted device and browser profile. Work from copied exports, keep destination backups, avoid public computers, and remove data that is unnecessary for migration. Catalog files may contain supplier costs, internal identifiers, unpublished products, or other confidential business information.

Questions

Use the public GitHub repository issue tracker for software and documentation questions. Never attach a private catalog, credentials, customer records, or supplier-confidential information to a public issue.
